<div class="cyber-prose max-w-none"><p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">今天是2025年最后一天。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">感觉有点恍惚。这一年过得，像坐过山车，又像是被什么东西推着跑。没想搞什么正儿八经的年终总结，就是想碎碎念几句，把脑子里这一团浆糊理一理。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">回想1月份那会，我是真想用AI偷懒。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">那时候刚装上 <strong class="font-semibold text-[var(--color-text-primary)]">Cline</strong>，心里盘算着以后代码让它写，我负责喝咖啡。结果上手一试，不行。真不行。简单的逻辑还凑合，稍微多说两句，上下文就爆了，做不了什么事。那时候用的 <strong class="font-semibold text-[var(--color-text-primary)]">DeepSeek Coder</strong>，后来换 <strong class="font-semibold text-[var(--color-text-primary)]">Chat</strong> 版，一样，完全不可用。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">&gt; 我当时就在想，这玩意离“甚至不需要程序员”还差十万八千里吧？</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">代码指望不上，我就去折腾生图。**SD1.5**，**SDXL**，**PONY**，**FLUX**，这几个模型轮着刷。那时候为了跑图，电脑机箱热得能煎蛋。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">惨的是中间硬盘崩了一次，CPU也烧了。数据全丢。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">看着黑屏那一刻我人都麻了。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">没办法，重新买硬盘，重新下模型，重新配环境。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">后来又觉得光有图没劲，开始搞视频和声音。**Index-TTS** 配音，**Wan2.0** 做小姐姐跳舞视频。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">我拿着这些东西去抖音发视频，想着能不能火一把。发了几个月，没多少浏览量。也没那个运营的天赋，这事就算黄了。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">到了4月，**GPT-4o** 出了原生图像功能。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">我一看，心态崩了。我哼哧哼哧调半天参数才出来的吉卜力风格，人家一句话就搞定了。除了 <strong class="font-semibold text-[var(--color-text-primary)]">NSFW</strong> 它不让画（说是年底出的成人模式也鸽到了明年一季度），其他的完全不输 <strong class="font-semibold text-[var(--color-text-primary)]">FLUX</strong>。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">这件事给我打击挺大。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">我突然意识到，我年初费劲学的技术，三个月就过时了。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">这速度太吓人了。如果不盯着最新消息，可能明天我还在用被淘汰的工具沾沾自喜。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">为了治这种焦虑，我得找药。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">我写了个 <strong class="font-semibold text-[var(--color-text-primary)]">CloudFlare-AI-Insight-Daily</strong>。思路很简单，用 CloudFlare 每天去抓 FOLO 的订阅源，扔给 AI 整理成日报。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">这次我学乖了，没用年初那些模型，用了 <strong class="font-semibold text-[var(--color-text-primary)]">Kilo</strong> 加 <strong class="font-semibold text-[var(--color-text-primary)]">Gemini-2.5-flash</strong>来写代码。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base"><strong class="font-semibold text-[var(--color-text-primary)]">1M 的上下文</strong> 是真的爽。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">年初让我头疼的上下文不够的问题彻底没了。代码基本全是它写的，我只负责看一眼，修修补补。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">做出来第一版，顺手发到了 L站 和 阮一峰周刊。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">本来没报啥希望，结果莫名其妙火了。第一次拿了100多个Star，到现在居然有1000多了。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">最离谱的是 FOLO 上的订阅。我在抖音发视频没人看，这个自动生成的日报居然有18k人订阅，一直霸榜到现在。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">&gt; 有时候事情就是这样，无心插柳柳成荫。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">这个项目给了我点底气，也给我带来了流量。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">后来 Google 发布 <strong class="font-semibold text-[var(--color-text-primary)]">Gemini CLI</strong>，导致 Flash 模型的额度骤降，不稳定。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">我不想付钱，也不想受气。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">我想起 Kilo也支持Gemini CLI，干脆把 Gemini CLI 给逆向了。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">于是有了 <strong class="font-semibold text-[var(--color-text-primary)]">AIClient-2-API</strong>。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">把 CLI 逆向成 API 接口，支持 OpenAI 和 Gemini 协议。这个项目发出去，又上了阮一峰周刊。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">后来顺手把 kiro 的 <strong class="font-semibold text-[var(--color-text-primary)]">Claude</strong>，**Qwen Code**，**Antigravity** 全逆向了，还支持多协议互转。现在手里的 Token 根本用不完。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">有了 Token 就想搞事情。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">我一口气搞了好几个站，包括播客工具、提示词工具、<strong class="font-semibold text-[var(--color-text-primary)]">AI人相大师</strong> 和 **遗产管理系统**。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">做提示词工具的时候，我搞了个 Build in Public 挑战：V我50，围观AI开发从零到一的全过程。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">说好一个月搞定网页、后台、桌面端。结果不到3周，一期功能全做完了。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">&gt; 二期到现在还没动，前两天群里还有人催更... 只能，假装没看见。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">最近在弄基于 <strong class="font-semibold text-[var(--color-text-primary)]">Next16</strong> 的出海应用模板，基础功能写差不多了，线上测试环境也搭好了。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">为了以后出海收款方便，前阵子还特意跑了趟香港，开了四个银行账户。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">回头看这一年，真的是被技术推着走。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">年初还在纠结上下文不够，年底现在的配置已经是神仙打架了：</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">写代码有 <strong class="font-semibold text-[var(--color-text-primary)]">Claude Code</strong>，**Codex**，**Trae**。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">文本有 <strong class="font-semibold text-[var(--color-text-primary)]">Gemini 3.0</strong>，还有平替 <strong class="font-semibold text-[var(--color-text-primary)]">豆包</strong>。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">生图有强得离谱的 <strong class="font-semibold text-[var(--color-text-primary)]">Nano Banana Pro</strong>，开源也有 <strong class="font-semibold text-[var(--color-text-primary)]">Flux</strong>。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">视频有 <strong class="font-semibold text-[var(--color-text-primary)]">Veo3.1</strong>，**Sora2**，开源有 <strong class="font-semibold text-[var(--color-text-primary)]">Wan2.6</strong>。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">音频有 <strong class="font-semibold text-[var(--color-text-primary)]">MiniMax</strong>，开源有 <strong class="font-semibold text-[var(--color-text-primary)]">Index-TTS2</strong>。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">全是好东西。那些差一点的，早就没人提了。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">但我现在反而没年初那么焦虑了。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">虽然总有行业毒瘤在吹牛，贩卖焦虑，说人类要完蛋。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">我现在的感觉是，AI 确实强，但离完全取代人类，还有段距离。它能帮我写代码，但它不知道我要写什么代码，也不知道为什么要写这个代码。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base"><strong class="font-semibold text-[var(--color-text-primary)]">它是个好手，但它不是我不干活的理由。</strong></p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">这一年被技术背刺了好几回，学的快，忘的也快，过时得更快。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">但这种紧迫感，逼着我不断去学，去试。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">挺充实的。</p>
<p class="my-5 text-[var(--color-text-secondary)] leading-7 text-base">就这样吧，2025，新年快乐，2026</p></div>
